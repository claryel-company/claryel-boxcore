# Licence map

## Code

Unless a file states otherwise, source code, Nix expressions, schemas, policy, tests and machine-readable examples in this repository are licensed under the Apache License 2.0.

The complete licence text is in the repository root `LICENSE` file.

SPDX identifier: `Apache-2.0`

## Documentation

Human-readable documentation in Markdown and public explanatory website-source facts is licensed under Creative Commons Attribution-ShareAlike 4.0 International unless a file states otherwise.

SPDX identifier: `CC-BY-SA-4.0`

Official licence text: https://creativecommons.org/licenses/by-sa/4.0/legalcode

## Generated translations

Generated website translations remain governed by the managed-web repository and must identify the canonical English source. Translation does not change the licence of the source material.

## Third-party material

Third-party code, data, names and assets retain their original licences and must be recorded before inclusion. A Pull Request that introduces a dependency or copied material must include:

- source and version;
- licence and compatibility decision;
- copyright notice where required;
- modifications made by CLARYEL;
- whether the material is included in a distributed artefact;
- dependency and supply-chain evidence.

## Private-to-public exports

An export from a private CLARYEL repository is not automatically releasable. The export record in `docs/PROVENANCE.md` must confirm that CLARYEL owns the relevant rights or has a compatible licence and that no customer or third-party restricted material is included.

## Grant-funded results

Every result financed under an eventual NGI Fediversity agreement must remain available under a recognised free and open-source licence in its entirety. Licence refinement during negotiation may improve ecosystem compatibility but may not remove freedoms from already published grant-funded results.

## Contributions

By submitting a contribution, the contributor confirms that they have the right to provide it under the licence applicable to the destination file. Maintainers may request a separate provenance or rights statement for substantial contributions.
